# 阿里客服助手 1.1.2

这是适用于 Chrome 的 Manifest V3 扩展。它读取已登录的阿里国际站客服页面，支持把选中的对话匹配到外贸人工作台客户。登录工作台后，可以核对 AI 提炼结果，再确认同步沟通记录、创建客户或登记询盘。

## 安装

1. 从仓库下载源码，或下载并解压 [扩展安装包](../../docs/downloads/alibaba-cs-helper-1.1.2.zip)。
2. 在 Chrome 地址栏打开 `chrome://extensions`，开启「开发者模式」。
3. 点击「加载已解压的扩展程序」。选中直接包含 `manifest.json` 的文件夹。使用仓库源码时，选中 `extensions/alibaba-cs-helper`。
4. 刷新已登录的阿里客服页面，再点击浏览器工具栏中的扩展图标打开侧栏。

## 连接工作台

在侧栏填写自己的 CRM 地址，默认示例为 `http://localhost:4173`。可选填同一 CRM 实例的备用地址。使用自己的工作台账号登录。CRM 需要支持 `/api/chat-sync/*` 接口。

扩展的网页读取脚本运行于 `message.alibaba.com` 和 `onetalk.alibaba.com`。扩展申请 HTTP 和 HTTPS 主机权限，以便连接用户填写的工作台地址。登录令牌保存在当前浏览器的扩展存储中，可在侧栏退出登录时清除。使用 AI 分析时，工作台会将提交的对话内容发送给该实例配置的模型服务。

复制或下载对话 JSON 时，导出的文件可能包含客户信息，请按业务资料保管。
